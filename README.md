# دفتر الشاحنة 🚚

تطبيق بسيط على الجوال لتسجيل رحلات الشاحنة ومصاريفها، ومعرفة صافي الموسم والوصول للهدف. يشتغل من المتصفح، ويتثبّت على الشاشة الرئيسية مثل أي تطبيق، ويعمل بدون إنترنت.

**الرابط:** https://mousabechir1701-del.github.io/my_truck1701/

## طريقة التثبيت على الجوال

1. افتح الرابط من **كروم**.
2. اضغط القائمة ⋮.
3. اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.

## المميزات

- **عدة شاحنات:** إضافة شاحنة، تغيير اسمها، حذفها، ولكل شاحنة عملتها وبياناتها.
- **الرحلات:** التاريخ، عدد الرحلات، أجرة الرحلة، **من / إلى**، وملاحظة اختيارية. عند اختيار خط سبق تسجيله تنعبّى الأجرة تلقائياً بآخر سعر.
- **المصاريف:** نافطة، أكل وشرب، زيت، عجلات، عطل وإصلاح، أخرى.
- **الملخص:** الدخل والمصاريف والصافي لليوم أو الشهر أو الموسم، مع عدد الرحلات ومتوسط الرحلة.
- **الهدف:** لكل شاحنة هدفها المستقل. اكتب مبلغ هدفك للعودة وشوف نسبة التقدم والمتبقي.
- **تذكير الصيانة:** مثل تغيير الزيت كل عدد معين من الأيام، مع تنبيه قبل الموعد وعند التأخر.
- **العملات:** دينار ليبي، فرنك سيفا (تشاد)، دولار، يورو، جنيه مصري، جنيه سوداني، نايرا، دينار جزائري، دينار تونسي.
- **اللغتان:** العربية والفرنسية.
- **وضع ليلي / نهاري:** زر ☀️/🌙 أعلى الصفحة، ويحفظ اختيارك.
- **المشاركة:** نسخ الملخص أو إرساله على واتساب.
- **نسخة احتياطية:** حفظ كل البيانات في ملف واسترجاعها لاحقاً. الاسترجاع يفحص الملف بدقة ويرفض أي ملف تالف أو غير صالح دون تغيير بياناتك، ويحتفظ بنسخة من البيانات السابقة قبل الاستبدال.

## البيانات والخصوصية

كل البيانات تنحفظ **داخل جوالك فقط** (في المتصفح) ولا تُرسل لأي سيرفر.
المبالغ تُحسب بدقة حتى 3 خانات عشرية. وإذا تعذّر الحفظ (مساحة ممتلئة أو التخزين معطّل) يظهر شريط أحمر واضح في أعلى الصفحة.
لهذا مهم تحفظ **نسخة احتياطية** من زر "حفظ نسخة احتياطية" بشكل دوري، لأن مسح بيانات المتصفح أو تغيير الجوال يمسح البيانات.

لنقل بياناتك لجوال جديد: احفظ نسخة من الجوال القديم، وافتح التطبيق في الجديد، واضغط "استرجاع نسخة".

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كامل (الواجهة والمنطق) |
| `manifest.webmanifest` | بيانات التثبيت كتطبيق (الاسم والأيقونات) |
| `sw.js` | يخلي التطبيق يشتغل بدون إنترنت ويجلب التحديثات |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | أيقونات التطبيق |

## تحديث التطبيق

1. في المستودع: **Add file ← Upload files**.
2. ارفع الملفات المعدّلة (تستبدل القديمة) واضغط **Commit changes**.
3. بعد دقيقة، افتح التطبيق مرتين وتتحدّث النسخة تلقائياً.

عند تغيير شكل أو ملفات التطبيق بشكل كبير، غيّر اسم النسخة في أول `sw.js` (مثلاً من `truck-v4` إلى `truck-v5`) عشان تنحذف الملفات المخزنة القديمة.

## النشر

يعمل عبر **GitHub Pages**: Settings ← Pages ← Deploy from a branch ← `main` / `(root)`.
